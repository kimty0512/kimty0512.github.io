SB LAB MULTI-PAGE HOMEPAGE

변경된 점
1. 메뉴를 누르면 같은 화면에서 스크롤하지 않고 별도의 HTML 페이지로 이동합니다.
2. 페이지가 열릴 때 제목과 설명이 순서대로 천천히 나타납니다.
3. 다른 메뉴를 누르면 현재 화면이 부드럽게 사라진 뒤 다음 페이지가 열립니다.
4. 모바일 메뉴도 포함되어 있습니다.

파일 구성
- index.html: Home
- research.html: Research
- projects.html: Projects
- people.html: People / Alumni
- publications.html: Publications
- gallery.html: Gallery
- contact.html: Contact
- 404.html: 잘못된 주소 안내
- style.css
- script.js
- assets/

GitHub에 반영하는 방법
1. 압축을 풉니다.
2. 압축을 푼 폴더 안의 모든 파일과 assets 폴더를 선택합니다.
3. GitHub 저장소에서 Add file → Upload files를 누릅니다.
4. 기존 index.html, style.css, script.js는 새 파일로 덮어쓰고,
   research.html 등의 새 페이지 파일도 함께 추가합니다.
5. Commit changes를 누릅니다.
6. GitHub Pages 반영에는 일반적으로 수 분 정도 걸릴 수 있습니다.

주의
- assets 폴더의 이미지는 임시 이미지입니다.
- People, Publications 등의 예시 텍스트를 실제 정보로 교체해야 합니다.
